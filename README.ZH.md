# pi-file-sidebar

[English](README.md) | **[简体中文](README.ZH.md)**

Pi 1.4.0 fullscreen 内的原生左侧文件树。宽窗口右侧保留 Pi 主界面、编辑器和原生对话滚动。窄窗口默认隐藏文件树，手动打开后临时覆盖会话左侧，返回输入框时收起；复用宿主 renderer。

0.2.0 同包集成 `/cd`：切换工作目录时保留当前会话。正式 TUI 实机验收尚未完成。

## 安装

### 远程安装（两种方式）

**方式 A：git 源（Pi 标准流程）**

```bash
pi install git:github.com/llc2214926/pi-file-sidebar
```

Pi 会把整个仓库克隆到 `~/.pi/agent/git/github.com/llc2214926/pi-file-sidebar`（设置 `PI_CODING_AGENT_DIR` 时用对应目录）并写入 `settings.json` 注册。目录保留 `.git`、`scripts/`、`tsconfig.json`、`package-lock.json` 等全部克隆内容，因此更新可用：`pi update git:github.com/llc2214926/pi-file-sidebar` 会 fetch 并对账到配置的 ref。安装需要 git 和一个 npm 包管理器（运行时本身零依赖，只声明宿主 peerDependencies）。

**方式 B：remote-install.sh（GitHub Release 纯净包）**

```bash
curl -fsSL https://raw.githubusercontent.com/llc2214926/pi-file-sidebar/refs/heads/master/scripts/remote-install.sh | bash
# 或指定版本
bash remote-install.sh 0.1.3
```

脚本从 Release 下载 `pi-file-sidebar-<版本>.tgz`（即 `npm pack` 白名单产物：仅 `extensions/`、`src/`、`package.json`、`README*`、`LICENSE`），先用 `pi install` 注册同一 git 源，再原子地把克隆目录替换为纯净包。最终目录只包含扩展运行所需文件 —— 没有 `.git`、`scripts/`、`tsconfig.json`。

**差异一览**

| | A：`pi install git:…` | B：`remote-install.sh` |
|---|---|---|
| 安装目录内容 | 完整仓库克隆 | 仅打包白名单文件 |
| 磁盘占用 | 仓库 + `.git`（约 420 KiB） | 仅包文件（约 180 KiB） |
| `pi update` | 可用（fetch 配置的 ref） | **不可用** —— 无 `.git`；升级需重跑脚本并传新版本 |
| 需要 GitHub Release tgz | 否 | 是（`v<版本>` 的 Release 附件） |
| 其他步骤 | 无 | 校验 `curl`/`tar`/`node`/`pi`、验证 Pi 1.4.0 与包内容，失败可回滚的原子替换 |

两种方式在 Pi 设置中注册的是同一个源字符串 `git:github.com/llc2214926/pi-file-sidebar`，占用同一个位置：先后安装会互相替换。任一方式安装后，在当前 Pi 执行 `/reload` 或重启 Pi。两者都只写 Pi 自己的 `settings.json` packages 项，不改 keybindings 和项目设置。

### 本地发布（源码仓库）

本地发布使用 `npm pack` 生成版本包，解包到 Pi 的独立安装目录后注册全局包。在源码仓库执行：

```bash
./scripts/publish-install.sh

# 仅校验并打包，不修改 Pi 安装或设置
./scripts/publish-install.sh --pack-only
```

脚本要求已有开发依赖（首次运行前执行 `npm install --ignore-scripts`），先运行类型检查，再打包；不上传 npm、不提交代码、不自动重载 Pi。

- 从 `package.json` 读取版本，不自动递增；包和清单输出到 `artifacts/releases/<版本>/`，npm 缓存放在 `artifacts/npm-cache/`，均不入库。
- 默认安装到 `~/.pi/agent/local-packages/pi-file-sidebar/<版本>`；设置了 `PI_CODING_AGENT_DIR` 时使用该目录。自动安装只接受 Pi 1.4.0。
- 同版本目录内容一致时复用，内容不同或目标为符号链接时拒绝覆盖。**修改发布内容后，先提升 `package.json` 版本号再发布。**
- 新版注册成功且核验持久化后，才移除同一安装根目录下其他版本的全局注册；保留旧版本文件，不处理其他位置的安装或项目级注册。有自定义资源过滤的侧栏注册需手动切换，不会被脚本覆盖。
- 失败时停止并保留诊断，不修改目录所有权、不强删活动锁。若旧注册清理失败，新旧注册可能同时保留；处理后重试脚本，成功前不要 `/reload`。

已解包的版本也可以手动注册：

```bash
pi install ~/.pi/agent/local-packages/pi-file-sidebar/0.2.0
```

该安装目录由本地版本包生成。安装后在当前 Pi 执行 `/reload` 或重启 Pi。运行时使用独立安装副本，不依赖源码仓库，不需要 npm 账号。

入口是 `extensions/index.ts`。包只声明宿主 peerDependencies，不携带第二份 Pi SDK。

当前开发/测试基线为 Pi **1.4.0**、Node **24.22.2**、macOS Apple Silicon。其他版本、平台与终端没有完成兼容矩阵，不能据此宣称支持。regular 模式隐藏树；RPC/print/JSON 不创建侧栏运行时、不输出 UI/ANSI。宿主布局或焦点能力不兼容、或其他扩展接管 root 时，本扩展不覆盖其布局；用 `status` 查看原因。

## 命令

| 命令 | 行为 |
|---|---|
| `/file-sidebar`、`/file-sidebar focus` | 显示并进入树焦点；窄窗使用左侧临时浮层 |
| `/file-sidebar on` | 启用自动显示，不主动夺取焦点；窄窗仍隐藏 |
| `/file-sidebar off` | 关闭、取消未确认动作/模态并恢复主界面 |
| `/file-sidebar refresh` | 刷新已加载且可见展开的目录；其他 dirty 目录在重新展开后处理 |
| `/file-sidebar width 32` | 设置本运行时宽度，接受整数 24–48；窄窗隐藏并排树，已打开的临时浮层按窗口裁减显示宽度 |
| `/file-sidebar lang zh`、`/file-sidebar lang en` | 切换整个侧栏的中英文界面并保存选择 |
| `/file-sidebar lang` | 查看当前语言和切换用法 |
| `/cd`、`/file-sidebar cd` | 打开同一个居中浮动目录选择器，切换时保留当前会话 |
| `/cd <编码路径>`、`/file-sidebar cd <编码路径>` | 直接切换；整个路径用 `encodeURIComponent` 编码 |
| `/file-sidebar status` | 模式/挂载或隐藏原因、宽度、焦点、缓存、待处理读取数与当前语言 |

默认激活键为 **Ctrl+Shift+E**。不更改用户 keybindings；若终端无法区分该键或其他扩展存在冲突，使用命令。树内同一快捷键返回 Pi 输入框。

低于并排显示阈值（默认宽度时为 97 列）时，`/file-sidebar`、`/file-sidebar focus` 和 Ctrl+Shift+E 会在左侧打开临时浮层。会话在下方仍保持全窗口宽度。Esc、Ctrl+C、激活键或插入引用返回输入框时，浮层收起；菜单、预览和帮助关闭时先回到文件树。放大窗口后恢复原来的并排布局。聚焦的并排树缩窗时自动切换为临时浮层；未聚焦的并排树缩窗后隐藏，需再次手动打开。帮助、操作菜单或预览打开时缩窗，模态不会被取消：树转为临时浮层并在模态关闭前保持隐藏，关闭模态后回到浮层树（窗口已放大则恢复并排）。窗口小于 **26 列 × 8 行** 时浮层关闭，打开中的模态仍会被取消。浮层显示宽度会按窗口裁减，保留分隔线及至少一列会话，不改动已确认宽度。

## 切换工作目录

选中目录后，Space 菜单新增以下动作（位于展开/折叠之后、复制之前）：

| 目录动作 | 行为 |
|---|---|
| 设为工作目录，保留当前会话 | 校验选中目录并直接切换 |
| 选择其他工作目录… | 从当前工作目录打开与 `/cd` 相同的选择器 |

文件和符号链接菜单不包含这两项。不新增全局快捷键。普通文件树仍以 `ctx.cwd` 为根；只有独立选择器可以向上浏览父目录和兄弟项目。

### 选择器按键

选择器像文件预览一样使用**居中、双线边框的浮动窗口**，不再全屏展示：宽度为终端的 85%，高度不超过终端的 90% 且含边框最多 30 行，周围仍可看到会话。各目录栏之间有竖线分隔，超长名称以 `…` 省略。选中被截断的名称时，会打开下述共用全名气泡；气泡可越过分栏或选择器窗口边界，但不夺取焦点。

| 选择器输入 | 行为 |
|---|---|
| ↑ / ↓、j / k | 上下选择；仅长按方向键会在约 1.1s / 2.6s 后加速至每次 2 / 3 项 |
| ← | 返回父目录/上一列 |
| → / l | 进入选中的子目录 |
| . | 显示/隐藏点目录与 `node_modules`，与左侧树统一 |
| r | 返回打开选择器时的当前工作区（`ctx.cwd`），不切换会话 |
| [ / ] | 完整名称气泡内容溢出时向前/向后翻页，不改变选择 |
| Enter | 选定高亮目录；`.` 行代表本列目录自身 |
| Esc / Ctrl+C | 取消，不生成会话副本或备份 |

在选择器中浏览任意目录后按 `r`，会回到工作区：收回为单栏、选中该栏的 `.` 行、清空滚动偏移并收起全名气泡，同时保留隐藏项开关。工作区列仍在时直接复用，否则仅重新读取该目录。这只是导航，不是确认切换或刷新；左侧树自己的 `r` 仍用于刷新，`h` 仍打开帮助。选择器中的 `h` 不再切换隐藏项。

选择器只异步读取已进入的层级，不递归、不监听、不跟随目录项中的符号链接。加载中、空目录与读取失败分别显示。文案跟随侧栏语言；这里的 `l` 是进入目录，不切换语言。文件名和路径仅清洗显示，不翻译、不改动磁盘路径。

直接参数是 **URI 编码路径**，不是 shell 引号参数，例如 `/file-sidebar cd %2FUsers%2Fme%2FMy%20Project`。对整个路径执行一次 `encodeURIComponent`；无效编码会被拒绝。相对路径以当前 `ctx.cwd` 解析，支持 `~` 和 `~/…`。明确指定的目标经 `realpath` 解析（包括符号链接），必须是有读/执行权限的目录。实际路径与当前目录相同则仅提示，不切换。不执行 shell。

### 会话与失败语义

- 要求 **Pi 1.4.0 TUI**、启用会话持久化、agent 空闲、无待发送消息、无阻塞模态/外部编辑器/调宽事务。`/cd` 也可用于 regular TUI，此时侧栏本身仍隐藏。非 TUI 静默。重复请求共用一个在途锁。
- 菜单先关闭并恢复焦点，再以显式 `expandPromptTemplates: true` 发送 `/file-sidebar cd …`。这是命令分发，不是聊天 prompt，不提交草稿，也不让模型执行目录切换。
- 以私有权限、独占创建 JSONL 快照，保留会话 ID、头部元数据、全部条目/分支与当前 leaf；不进入模型上下文的 `cd-picker` marker 记录 `{ from, to }`。默认存储切换到目标目录对应的会话目录；显式配置的会话存储目录保持不变。**不会**自动恢复目标项目上次会话。
- Pi 替换 runtime，并按宿主 trust 规则重新加载 AGENTS.md 等 cwd 相关资源。旧侧栏/编辑器运行时清理，新树使用新根、宽度重置 **32**；成功保存的语言偏好保留。这不同于退出树焦点，后者保留原编辑器对象。
- 切换前捕获草稿文本，仅通过 `withSession` 的新上下文恢复。**不保证光标位置**；恢复失败会告警，不伪装成功。
- 确认接管后，将原文件重命名为 `source.cd-backup`；已有同名备份时增加 UUID 后缀。尚未落盘的源会话可能无需归档。`EXDEV` 回退独占复制并保留原文件、发出告警。其他归档失败也告警并保留原件，新会话继续可用。
- 宿主取消切换或接管前抛出可捕获错误时，将目标副本重命名为 `.cd-abandoned`（冲突时加 UUID），绝不删除，保留原会话。写入中断的部分文件也尽量隔离；重命名失败则提示仍存留的 `.jsonl` 路径，供手动处理。`.cd-backup` 和 `.cd-abandoned` 不出现在 `/resume`。
- **宿主限制：**Pi 1.4.0 可能先销毁旧 runtime 再创建新 runtime；交互层致命错误处理可能直接 `process.exit(1)`，扩展的 catch 来不及执行。此路径（或进程被终止）**不保证恢复 UI，也不保证自动改名 `.cd-abandoned`**。切换前会显示原会话和目标副本路径；未接管前不归档原会话，但目标可能仍为 `.jsonl`。重启时用 `pi --session '/原会话绝对路径.jsonl'`，或通过 `/resume` 选择原会话。仅在确认副本未被使用后检查并手动移走它。不拦截进程退出、不修改宿主私有实现。

### 从独立 cd-picker 升级

不要同时加载 `~/.pi/agent/extensions/cd-picker.ts` 和本版本：两者都注册 `/cd`。先用 `pi --no-extensions -e ./extensions/index.ts --tui-mode fullscreen` 验证源码。实机验收通过后，备份独立扩展及现役安装，安装 0.2.0，再把旧扩展移至 `cd-picker.ts.disabled`，随后 `/reload` 并检查命令冲突。源码开发不会执行安装、停用或全局配置修改。回滚操作见源码仓库中的 [rollback-steps.md](rollback-steps.md)。

| 树内输入 | 行为 |
|---|---|
| ↑ / ↓ | 移动选择；按住 ↑/↓ 会加速（按住约 1.1 秒后每次跳 2 项，约 2.6 秒后跳 3 项） |
| Home / End | 选择首项 / 末项 |
| → / ← | 展开目录；折叠目录或回父目录 |
| Ctrl+U / Ctrl+D | 树内半页移动 |
| Enter | 目录展开/折叠；普通文件只读预览 |
| Space | 原生操作菜单，支持键盘和鼠标选择 |
| y | 复制相对路径；绝对路径在菜单中 |
| a | 插入文件路径引用，返回主输入框，不发送 |
| e | Pi 空闲时启动选中文件的外部编辑器 |
| r | 手动刷新 |
| . | 显示/隐藏点项与 node_modules |
| w | 进入键盘调宽 |
| h | 打开完整按键帮助 |
| l | 切换侧栏中英文并保存选择（帮助中也可用） |

文件单击只选择；双击同一文件预览。目录展开标记可点击。滚轮只滚动侧栏，不因 hover 夺焦点，边界不传到主对话。滚动条支持拖动；不拖动文件或分隔线。

**PageUp/PageDown 策略：**普通树焦点下保留 Pi 的主对话翻页；树用 Ctrl+U/Ctrl+D。在捕获焦点的预览或帮助面板中，PageUp/PageDown 控制该面板，不滚动主对话。主输入框的 Tab、Ctrl+B 等原有行为不改动；树内未定义的普通键不会偷偷写入主草稿。

## 完整名称气泡

目录选择器与左侧文件树复用同一个名称提示组件。有焦点的选中项名称被截断时，自动用**不抢焦点的圆角气泡**显示全名。气泡可以宽于侧栏或某一分栏，临时覆盖一部分会话，但不改变侧栏或主会话布局。气泡最多宽 80 列、高 12 行，并进一步限制在终端边界以内。

名称按终端显示宽度自动换行。窄/矮窗口一次放不下时，可用 **`[` / `]`** 翻页，或把鼠标移到气泡上滚轮查看，所有行均可访问。这些操作仅滚动气泡，不改变树选择或滚动主对话；普通树焦点下的 PageUp/PageDown 仍留给主对话。气泡不捕获键盘焦点，Esc 保持所属文件树/选择器原有的退出行为。

选中可完整显示的名称、离开树焦点、打开模态、调宽、隐藏/销毁侧栏或把选中行滚出视口时，树的气泡收起。缩放终端会重新定位和换行，保持提示在屏幕内。文件名只清洗显示、不翻译；显示提示不读取文件正文、不重扫目录，也没有定时跑马灯或轮询。

## 界面语言

首次默认**中文**，支持整个侧栏中英文切换：

```text
/file-sidebar lang en   切换为 English
/file-sidebar lang zh   切换为中文
/file-sidebar lang      查看当前语言
```

树有焦点时或在 `h` 帮助内按小写 `l` 可快速切换，支持扩展键协议。标题中的 `l:EN` / `l:ZH` 表示按键及目标语言。调宽、操作菜单、预览和其他阻塞模态不接管该单键；目录选择器中的 `l` 用于进入子目录。主输入框中的 `l` 仍是普通输入，不修改 Pi keybindings。

- 翻译范围：树标题与状态、底部提示、调宽提示、操作菜单、目录选择器与切换反馈、帮助表格、预览提示、命令反馈和本扩展定义的错误。命令/快捷键注册说明使用固定中英双语，Pi 主界面不随之切换。
- **文件名、路径和文件正文不翻译**；复制、引用和外部编辑仍使用原始路径，底层系统/第三方错误保留原始诊断并清洗显示。
- 切换立即重绘，不重建树、ScrollView 或主编辑器，不重新读取目录/正文，不改变树选择、已确认宽度、焦点或草稿。帮助中的表格按新语言重新换行，滚动偏移保留并限制在有效范围内。

语言偏好独立保存到 **`<agent-dir>/file-sidebar.json`**，默认是 `~/.pi/agent/file-sidebar.json`；遵循 `PI_CODING_AGENT_DIR`，不修改 Pi 的 `settings.json`、`keybindings.json`、项目设置或安装副本。例如：

```json
{ "language": "en" }
```

同一 agent 目录下跨项目、会话和 `/reload` 记忆；off/on 不重置语言。启动时只读，只有明确切换才写入；保存使用串行队列与同目录临时文件原子替换，保留其他 JSON 字段。正常 reload/会话替换会等待已发起的保存。没有 watcher 或轮询：其他已运行 Pi 不会自动跟随，多进程以最后成功保存的值为准，下次启动或 reload 读取。

配置缺失时使用中文，不自动创建文件。无效配置会告警并暂用中文；拒绝符号链接、非普通文件和超过 16 KiB 的配置。保存失败时告警，本次界面仍保持所选语言，但下次加载以磁盘内容为准；不会为了保存而覆盖损坏的 JSON，请先修复该扩展配置再重试。

## 按键帮助

树有焦点时按 `h`，以“按键｜功能”（英文为 “Key｜Action”）两列表格显示完整说明，按树内导航、文件动作、调宽、操作菜单和只读预览分组；操作菜单及主对话翻页键显示 Pi 当前配置。默认宽度下底部简易提示为 `Enter 预览 · Space 操作 · h 帮助`，英文为 `Enter View · Space Menu · h Help`；窄侧栏压缩 Enter/Space 提示以保留 `h` 帮助入口。`w` 仍用于调宽。

帮助弹窗随终端宽度调整（占窗口的 85%），表格铺满弹窗可用宽度。按键列按内容分配并为功能列保留空间，两列独立换行；窗口缩放时重新计算列宽，长键名和中文说明不会因变窄而被横向截断。表头固定显示，滚动只影响分组与操作行。

帮助支持 ↑/↓ 滚动、Ctrl+U/Ctrl+D 半页、PageUp/PageDown 翻页、Home/End 跳到首尾及鼠标滚轮。按 `l` 在面板内即时切换语言，不关闭帮助；按 `h`、Esc、Ctrl+C 或点击底部提示关闭，返回原树选择，不修改主输入框草稿。短窗口中可滚动查看全部说明；调宽或其他阻塞模态期间不打开帮助。

## 键盘调宽

默认 32 列，分隔线 1 列。并排显示为主界面至少保留 64 列，默认显示阈值是 **97 列**；并排和临时浮层均要求高度至少 **8 行**。

- 树有焦点且没有阻塞模态时，`w` 进入调宽。
- ←/→ 调整 1 列；支持扩展键协议的终端可用 Shift+←/→ 调整 4 列。
- 并排候选范围为 `24 … min(48, 终端列数 − 65)`；临时浮层为 `24 … min(48, 终端列数 − 2)`。上限不足 24 时不能进入。
- 即时预览保留主 root、编辑器、树和 ScrollView，不读取目录；并排布局变化只重建自有 HStack。
- Enter 确认，Esc 恢复进入前宽度，两者均回树导航。
- Ctrl+C/激活键取消后回 Pi 输入框。
- 离开树、阻塞模态、off、reload、会话/模式替换、宿主失效时取消未确认值。
- 缩窗使并排候选不可见时先恢复原宽度；原宽度仍能显示则保留树焦点，否则隐藏并释放焦点。临时浮层在候选宽度不再适合窗口时取消调宽，显示宽度按窗口裁减；少于 26 列或 8 行时关闭。
- off/on 保留已确认宽度、选择和展开；reload/新运行时回默认 32。宽度不写入持久配置（与语言偏好不同）。

## 文件动作与安全边界

只读预览、目录选择器、Space 操作菜单和 `h` 按键帮助统一使用双线边框，边框颜色跟随当前主题；主文件树及主对话布局不变。

### 只读预览

只在 Enter、双击或菜单明确选择时读取正文。支持 UTF-8，显示路径、行号、语法高亮、滚动与截断说明。实际读取上限 **512 KiB**，显示上限 **5000 行**；末尾截断的 UTF-8 字符不会变成乱码。空文件、二进制、非 UTF-8、权限和消失错误有说明。预览不写文件、不改变草稿。Esc 或点击底部提示行关闭，返回原树选择。

### 复制与引用

复制使用 Pi 公开 `copyToClipboard()`，保留路径原始字符，不复用清洗后的 UI 字符串。目录和链接可以复制。

引用在动作前重新验证普通文件，通过 `pasteToEditor()` 插入当前光标，并在两侧加边界空格。例如 `@src/a.ts`、`@"docs/design notes.md"`。含引号/反斜杠等路径采用 JSON 字符串编码，可逆；控制字符路径明确拒绝引用，可改用复制。目录和符号链接不作为文件引用插入。

引用只是草稿文本，不是附件上传；文件动作不读取正文注入上下文，也不提交草稿。唯一的 `sendUserMessage` 调用是上述明确选择的目录菜单桥接，并显式开启命令展开；不调用模型 API。

### 外部编辑器

优先级与 Pi 一致：可信项目/用户的 `externalEditor`，然后 `$VISUAL`、`$EDITOR`，最后平台默认（本机为 nano）。设置只读，尊重项目 trust，不创建配置锁或写回迁移。

命令解析为程序与独立 argv；支持引号和反斜杠转义，不执行 shell 管道、重定向或变量插值。文件以独立的绝对路径参数打开，不创建 prompt 临时副本。

要求 Pi idle；启动前再次检查状态。先 stop TUI，异步启动进程，再在正常、非零或启动失败路径恢复 TUI。关闭/替换会话先等待被终止的旧编辑器进程结束，旧结果不会启动新上下文的 renderer。

**GUI 等待语义：**请配置 `code --wait`、`open -W -n -a TextEdit` 等等待命令。`open -W` 等待 app 退出；没有等待参数时，进程返回只代表启动命令结束，不代表编辑完成。关闭 Pi 不会擅自关闭已经独立启动的 GUI 文稿窗口。

## 刷新与目录边界

以 `ctx.cwd` 为固定根，异步按层读取，不扫描未展开后代。默认隐藏点项、`.git` 和 `node_modules`。符号链接不自动展开或预览；目录加载和文件动作均重新检查链接/根范围。

刷新来源：首次显示/展开、手动、重新进入树、成功 write/edit/bash、外部编辑器返回。工具事件只标记 dirty，40ms 去抖；同目录单飞，读取中新 dirty 不丢失。隐藏或折叠的目录暂停主动读取；旧 runtime/已移出节点的结果丢弃。

**没有 watcher。** 外部修改不保证即时出现，用 r 或重新进入侧栏刷新。侧栏本身不新建、重命名、移动、删除或保存项目文件；仅用户主动的外部编辑器可以改目标文件。语言切换只写上述扩展专用偏好文件。用户明确触发的 `/cd` 另按上述语义写入与归档 Pi 会话文件，不移动项目文件。

## 开发

保留正式源码、依赖与项目配置。类型检查：

```bash
npm run typecheck
./node_modules/.bin/tsc -p tests/tsconfig.json
node --import tsx --test tests/*.test.ts
```

自动回归覆盖会话快照、注入的文件系统/替换错误、选择器导航、命令注册/编码，以及 Pi 1.4.0 renderer 和输入路由配合内存终端。另覆盖宿主已捕获本帧浮层列表之后收起全名气泡的时序：已卸载气泡的尺寸 getter 仍有效，旧组件不能渲染后来创建的气泡；不替代真实终端验收。
